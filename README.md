# Shirogane Universe — Site officiel

Site vitrine statique et responsive consacré à **Shirogane Universe**.

## Structure

- `index.html` — contenu et structure de la page
- `styles.css` — identité visuelle, responsive et animations
- `script.js` — navigation mobile, apparitions au défilement et fond stellaire
- `favicon.svg` — icône du site
- `.nojekyll` — compatibilité GitHub Pages

## Publication avec GitHub Pages

1. Créer un dépôt public, par exemple `shirogane-universe`.
2. Ajouter tous les fichiers à la racine de la branche `main`.
3. Ouvrir **Settings → Pages**.
4. Dans **Build and deployment**, sélectionner **Deploy from a branch**.
5. Choisir la branche `main`, dossier `/ (root)`, puis enregistrer.

L’adresse sera généralement :

`https://<nom-utilisateur>.github.io/shirogane-universe/`

## Principes éditoriaux

- aucune image générée ;
- contenu public sans spoilers majeurs ;
- progression par paliers de Souffles ;
- séparation entre informations publiques et archives de fin de série.
